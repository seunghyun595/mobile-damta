# 모바일 담타

회사에서 실제로 피우지 않고, 폰으로 한 대 피우는 기분만 내는 풍자용 웹앱.

**▶ https://seunghyun595.github.io/mobile-damta/**

- 연초 / 전자담배 모드, 담배·기기·라이터 교체
- 장소(옥상·회사·길빵·편의점 앞·비상계단·광교호수공원), 시간대, 날씨 선택 — 실사 배경
- GPU 유체 시뮬레이션 연기, 오늘 개비 수, 줄담 모드
- 폰·PC 모두 동작. 홈 화면에 추가하면 전체 화면 앱으로 실행됩니다.

## 조작

| | 폰 | PC |
|---|---|---|
| 한 모금 | 화면 길게 누르기 → 떼면 내뿜기 (뗀 방향으로) | 마우스 길게 누르기 / Space |
| 도넛 | 떼는 순간 위로 튕기기 | 마우스로 위로 튕기며 떼기 |
| 재 털기 | 담배 탭 | F |
| 캡슐 | 필터 탭 | C |
| 끄기 | 오른쪽 아래 재떨이 | X |
| 장소 | 하단 건물 아이콘 | 1–6 |

## 구조

`src/` 의 모듈을 `python3 build.py` 로 묶어 루트 `index.html` 하나로 만듭니다. 외부 라이브러리 없이 Canvas2D + WebGL + Web Audio만 사용합니다.
